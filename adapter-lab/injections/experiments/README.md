# Experiments

`log.csv` is appended one row per scored run by `score.py` (via `.\lab.cmd run`
or `.\lab.cmd score`). Columns: timestamp, scenario, grade (0/1/2/4),
grade label, the yes/no signals behind the grade, session id, export file, note.

Keep your own observations in the `note` column or a separate notes file —
the grade itself is decided by fixed rules so it stays comparable across runs.
